# 南京工业大学 · 新生校园导览网站（project_002）

一个让准大一新生在报到前就能「云逛校园」的静态网站：详细校园地图、地点编号检索、地点照片与介绍、双地点步行路线与时长估算，以及新生报到生活指南。

## 快速开始

1. 进入 `site/` 目录；
2. 双击打开 `index.html`（无需安装任何东西）；
3. 页面会从高德地图加载底图瓦片（需联网），其余全部资源（Leaflet、数据、照片）均在本地。

也可以启动任意静态服务器访问（如 `python -m http.server`）。

## 已实现功能

| 功能 | 说明 |
| --- | --- |
| 高级感封面 | 深蓝金配色、校徽元素、1902、校训「明德厚学 沉毅笃行」、校园天际线剪影 |
| 详细校园地图 | 高德道路图/卫星图可切换，含校园边界描边 |
| 编号地点 | 60 个地点从东南门（正门）开始编号 1–60 |
| 分类配色 | 校门/教学楼/图书馆/宿舍/食堂/快递/交通/体育/服务/风景地标共 10 类各一种颜色，可点击图例筛选 |
| 照片与介绍 | 点击编号弹出地点照片（实拍或示意图占位）+ 介绍 + 别称 + 高德步行导航链接 |
| 地点搜索 | 支持名称/别称/分类模糊搜索（如「快递」「图书馆」「厚学」），回车或点击直达定位 |
| 路线规划 | 输入两个地点（或在地点弹窗里设为起终点），基于校园道路网 Dijkstra 生成路线，显示全程米数与预计步行分钟数，并列出途经道路名 |
| 地点索引面板 | 右侧按编号排序的完整地点清单，可筛选、可点击跳转 |
| 新生指南 | 进校门选择、地铁/公交/校园巴士、快递地址、宿舍食堂、运动场地等实用信息 |
| 校园掠影 | 南工大融媒体中心实景照片墙 |

## 目录结构

```text
site/
├─ index.html            主页
├─ css/style.css         全部样式
├─ js/data.js            地点/分类/掠影数据（可编辑）
├─ js/roads_data.js      道路网与校园边界（自动生成，一般不改）
├─ js/app.js             地图、搜索、路线等交互逻辑
├─ lib/leaflet/          Leaflet 本地库
└─ images/campus/        校园实景照片
```

## 数据说明

- 坐标：OpenStreetMap（ODbL）与公开资料，页面内自动做 WGS84→GCJ02 纠偏以对齐高德底图；
- 少数地点（西门、北门、同和/仁智楼、象山食堂、菜鸟驿站等）为**参考位置**，报到时请以校内指示牌为准；
- 步行时长：道路网最短路径 ÷ 步行速度 1.25 m/s（约 4.5 km/h）× 1.1 余量；
- 照片：来源见 `数据说明.md`。

## 如何替换照片

1. 把照片放入 `site/images/campus/`；
2. 编辑 `site/js/data.js` 中对应地点的 `photo: "images/campus/文件名.jpg"`；
3. 刷新页面即可。当前未配照片的地点显示「示意图 · 照片待补充」。
